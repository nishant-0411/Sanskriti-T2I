The request can be in any language, for example Hindi, Bengali, Tamil, Telugu, Marathi, Gujarati, Kannada, Malayalam, Punjabi, Odia, Assamese or English.
Respond with JSON only, in this exact shape:
{"language": "Hindi", "translation": "...", "keywords": ["term1", "term2"]}
- "translation": a faithful English translation of the whole request. Keep every element of it.
- "keywords": culturally specific terms in English, suitable for a Wikipedia search:

  Include the setting if it is culturally specific (for example "Indian village", not just "village").
  Ignore generic words such as family, house, people.
